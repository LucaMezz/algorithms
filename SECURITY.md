# Security Policy

## Supported Versions

This project is in early development and has not published a stable release yet.
Security fixes will be applied to the default branch until versioned releases are
available.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

If GitHub security advisories are available for this repository, use a private
security advisory. Otherwise, contact the maintainer privately through the best
available channel listed on the project profile.

Include as much detail as you can:

- A description of the issue.
- Steps to reproduce it.
- The affected version, commit, or branch.
- Any known impact or workaround.

## Scope

This package implements educational algorithms and data structures. Security
reports are most likely to involve packaging, dependency configuration,
documentation that encourages unsafe usage, or denial-of-service behavior caused
by unexpected algorithmic complexity.

## Response Expectations

Reports will be acknowledged as soon as practical. Confirmed vulnerabilities
will be fixed on the default branch, documented in the changelog when
appropriate, and released once the project has a release process.
